## Patterns & root causes

- **Pattern: Multi-dimensional DoR underspecification**
  Root cause: The MNT-7 card was written quickly, and each DoR run caught one new dimension rather than all at once. The card-reviewer passes sequentially — it stops at the first set of failures and doesn't enumerate every remaining gap. Six dimensions were caught over five passes: E2E missing impeccable, UAT not mechanically reproducible, unit test missing a second case, Files missing the frontend component, AC describing test implementation rather than observable outcomes, global status count stale.

- **Pattern: Card left open after manual multi-PR implementation**
  Root cause: When a fix spans multiple iterative PRs (MNT-7 went through 6+ PRs as the implementation was refined), there is no hook or process to ensure the card gets marked `[x]` when the last substantive commit lands. The ship-task pipeline marks done on its own Ship phase; manual work bypasses it.

- **Pattern: Completed branches with no PR**
  Root cause: No end-of-session sweep exists for remote branches that are ahead of develop but have no open PR. The work is done but invisible until someone checks `git branch -a` manually.
